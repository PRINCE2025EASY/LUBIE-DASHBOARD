# Deploy online: Render (web) + Aiven (MySQL)

Why these two: `docs/DEPLOYMENT_OPTIONS.md`. You create both accounts yourself (free, no card)
and type every password and key into the providers' own pages or your local shell. Never paste
them into chat, e-mail or the repository.

Time needed: about 45 minutes.

## 1. Database on Aiven

1. Sign up at https://console.aiven.io (GitHub or e-mail). Choose the Free plan.
2. Create service > MySQL > Free plan > the European region offered. Name it `lubie-mysql`.
3. When it shows Running, open Overview > Connection information. You need:
   Host, Port, User (`avnadmin`), Password (stays in Aiven), Database (`defaultdb`), and the
   CA certificate: click Download and save it as `C:\xampp\htdocs\lubie-dashboard\storage\aiven-ca.pem`.
   (`storage/` is excluded from git.)

## 2. Create the schema from your computer (XAMPP Shell)

Your XAMPP PHP connects to Aiven over TLS. These `set` lines live only in this Shell window and
override `.env`. Keep the quotes: they protect passwords that contain & or ^.

    cd C:\xampp\htdocs\lubie-dashboard
    set "DB_HOST=<Aiven host>"
    set "DB_PORT=<Aiven port>"
    set "DB_NAME=defaultdb"
    set "DB_SSL_CA=C:\xampp\htdocs\lubie-dashboard\storage\aiven-ca.pem"
    set "DB_SSL_VERIFY=1"
    set "DB_USER=avnadmin"
    set "DB_PASSWORD=<type the Aiven avnadmin password here>"
    php bin/console.php migrate

Demonstration data (synthetic) for the usability sessions, optional:

    php bin/console.php seed:demo --yes

Create the least-privilege app account (it asks for the avnadmin password, then a new 12+
character password for the app; write the new one down for step 3):

    php bin/console.php setup:app-account --owner=avnadmin --host=% --require-ssl

Check with the app account:

    set "DB_USER=lubie_app"
    set "DB_PASSWORD=<the new app password>"
    php bin/console.php doctor

Close the Shell window afterwards so the passwords are gone. Without demo data, create the
first Administrator now: `php bin/console.php setup:first-admin` (in a Shell with the
`lubie_app` settings above).

## 3. Web service on Render

1. Sign up at https://dashboard.render.com with your GitHub account. Allow access to
   `PRINCE2025EASY/LUBIE-DASHBOARD` only.
2. New > Blueprint > choose the repository. Render reads `render.yaml`: a free Docker web
   service in Frankfurt, deployed from `main`, with APP_KEY, BACKUP_ENCRYPTION_KEY and
   BACKUP_TOKEN generated by Render.
3. Render asks for the values marked secret. Type them in:
   - `DB_HOST`, `DB_PORT`: from Aiven
   - `DB_PASSWORD`: the app password from step 2
   - `DB_SSL_CA_PEM`: open `aiven-ca.pem` in Notepad and paste the whole text
4. Apply. The first build takes about 5 minutes. The service address looks like
   `https://lubie-dashboard-xxxx.onrender.com`.

## 4. Check the live site

1. Open `https://<your address>/health`. Expect `{"status":"ok","db":"ok"}`.
2. Open the address, log in (demo: `admin_demo`, password in `database/seed_demo.sql`).
3. Administrator > Summary > Set-up checks: all OK except SMS (sandbox) is expected.
4. Administrator > Audit trail: your login row must show your own public IP address
   (search "what is my IP"). If it shows a 10.x or 172.x address, set `TRUSTED_PROXY_HOPS=2`
   in Render > Environment and redeploy.
5. On a phone: open the address in Chrome, menu > Install app. Switch on airplane mode,
   reopen: the app shell and the last data open, and progress entries queue.

## 5. Backups

- Aiven keeps its own backups of the free service.
- Off-site copy of the app's encrypted backup: in GitHub > Settings > Secrets and variables >
  Actions, add `LUBIE_URL` (your Render address) and `LUBIE_BACKUP_TOKEN` (copy BACKUP_TOKEN
  from Render > Environment). Then Actions > Backup > Run workflow. The encrypted file is kept
  14 days as a workflow artifact. Switch on the daily schedule in `.github/workflows/backup.yml`
  after the repository is private.
- Restore drill (RTO 4 hours): download the artifact, then in the XAMPP Shell with
  `BACKUP_ENCRYPTION_KEY` set to Render's value and an empty local database:
  `php bin/console.php restore:verify --file=<file> --target=<empty database>`.

## 6. Before real company data

Remove demo data (`database/remove_demo.sql`), change every demo password, make the repository
private, review Act 843 (see `docs/DEPLOYMENT_OPTIONS.md`), and decide on a paid instance if the
one-minute wake-up is not acceptable.

## Undo

Render: Settings > Delete web service. Aiven: Service > Delete. GitHub secrets: delete
`LUBIE_URL` and `LUBIE_BACKUP_TOKEN`.
